## BDD + TDD tutorial (Lecture 8, Slide 6)

Start with the [MoovOver handout](moovover/README.md). It now includes a runnable
Cucumber outer loop around the RSpec exercises:

```text
Cucumber RED → RSpec RED → RSpec GREEN → Cucumber GREEN
```

The student starter deliberately leaves the controller implementation and
search form unfinished. Follow the handout to observe RSpec passing while
Cucumber still fails, then connect the UI to complete the user scenario.

### For 08-TDD demo, it is on the `main` branch

### For 08-TDD coverage demo, it is on the `TDD-coverage` branch

So you need to checkout the `TDD-branch` to see the coverage demo:
```
git checkout TDD-coverage
```
